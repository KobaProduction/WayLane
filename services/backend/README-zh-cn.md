# WayLane Backend

项目所有者：**Intens**。初始代码基于 PasarGuard，保留原作者署名及 AGPL-3.0 许可证义务。

**当前功能：** FastAPI、用户与节点管理、Xray、WireGuard 和内置 HTML 订阅页面。

**规划中，尚未实现：** 独立 `waylane-frontend` 仓库中的 Vue 3 界面、sing-box、AmneziaWG 与高可用网络架构。

对于 Intens，商业订阅、支付和公共订阅网关仍由 `vpn-core` 提供。未经独立迁移验证，请勿直接替换生产环境。

来源和许可证说明见 [UPSTREAM.md](UPSTREAM.md)。
