# WayLane Backend

Владелец: **Intens**. Исходный код основан на PasarGuard Panel и сохраняет совместимость с существующим API и нодами.

**Реализовано в текущем baseline:** FastAPI, управление пользователями VPN, нодами Xray/WireGuard, лимитами, форматами подписок и встроенная HTML-страница подписки.

**Планируется, но не реализовано:** интерфейс Vue 3 (папка `services/frontend` в общем репозитории WayLane), sing-box, AmneziaWG, гибкое управление ядрами и распределённая отказоустойчивость.

Страница подписки пока обслуживается backend. Публичный Subscription Gateway и коммерческие подписки Intens остаются в `vpn-core`.

Сборка frontend производится отдельно и передаётся готовым артефактом через `scripts/install_frontend.sh`. Не запускайте на действующей инфраструктуре до отдельной миграции.
